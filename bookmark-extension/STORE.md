# Chrome Web Store listing

## Name
Bookmark

## Summary
Save the page you're reading to your private Bookmark shelf.

## Description
Bookmark keeps the page open in front of you, including pieces that only appear while you're signed in.

Use the toolbar button, the right-click menu, or Alt+Shift+S (Option+Shift+S on a Mac). If the shelf is locked, unlock it once in Chrome at bookmark.erica-hu.com, then save again.

This extension is for the private Bookmark shelf at bookmark.erica-hu.com.

## Category
Productivity

## Language
English

## Privacy policy URL
Host `privacy.html` on the site (for example https://bookmark.erica-hu.com/bookmark/extension-privacy.html) or paste that file to any public HTTPS URL, then put the URL in the store listing.

## Single purpose
Save the current page to the user's Bookmark shelf.

## Permission justifications
- activeTab: read the page the user asked to save
- scripting: copy the open page so signed-in articles keep their full text
- contextMenus: offer Save to Bookmark from the page menu
- storage: remember the last save result for the popup
- host permission for bookmark.erica-hu.com: send the saved page to the private shelf
